💡 避坑与实用建议

  • 公益中转站（谨慎使用）：网上一些通过 Star 项目换 API 的中转站极不稳定，随时可能跑路，仅适合临时测试，切勿用于正式产品。
  • 注意额度刷新机制：有的平台是按天重置（如火山引擎、Google），有的是注册一次性赠送（如智谱、阿里云）。如果是赠送型额度，记得关注有效期。
  • 接口兼容性：绝大多数平台都兼容 OpenAI 的 SDK 格式。这意味着你只需要把代码里的 base_url 和 api_key 换一下，就能无缝切换不同的模型服务商。
